<trans-unit id="tu7" xml:space="preserve">
<source xml:lang="en-US">Browse to the <ph id="1" ctype="x-STRONG_EMPHASIS">**[!UICONTROL </ph>Schemas<ph id="3" ctype="x-LINK_REF">]**</ph> menu, and locate editable schemas using the filters.</source>

</trans-unit>
<trans-unit id="tu8" xml:space="preserve">
<source xml:lang="en-US">Select the schema name in the list to open it and click the <ph id="1" ctype="x-STRONG_EMPHASIS">**[!UICONTROL </ph>Screen edition<ph id="3" ctype="x-LINK_REF">]**</ph> button in the schema details view to access the screen definition.</source>
<target xml:lang="en-XX">Wählen Sie den Schemanamen in der Liste aus, um das Schema zu öffnen, und klicken Sie in der Ansicht der Schemadetails auf die Schaltfläche <ph id="1" ctype="x-STRONG_EMPHASIS">**[!UICONTROL </ph>Bildschirmbearbeitung<ph id="3" ctype="x-LINK_REF">]**</ph>, um die Bildschirmdefinition aufzurufen.</target>
</trans-unit>
<trans-unit id="tu9" xml:space="preserve">

<target xml:lang="en-XX">Gehen Sie zum Abschnitt <ph id="1" ctype="x-STRONG_EMPHASIS">**[!UICONTROL </ph>Konfiguration der Bestandsliste<ph id="3" ctype="x-LINK_REF">]**</ph> und klicken Sie auf das Symbol mit den Auslassungspunkten über der Tabelle <ph id="5" ctype="x-STRONG_EMPHASIS">**[!UICONTROL </ph>Benutzerdefinierte Filter<ph id="7" ctype="x-LINK_REF">]**</ph> und wählen Sie dann <ph id="9" ctype="x-STRONG_EMPHASIS">**[!UICONTROL </ph>Attribute auswählen<ph id="11" ctype="x-LINK_REF">]**</ph> aus.</target>

<trans-unit id="tu13" xml:space="preserve">
<source xml:lang="en-US">A direct attribute of the schema, for example a code or a category.</source>
<target xml:lang="en-XX">Ein direktes Attribut des Schemas, z. B. ein Code oder eine Kategorie.</target>
</trans-unit>
<trans-unit id="tu14" xml:space="preserve">
<source xml:lang="en-US">A link attribute, for example a brand linked to a product. In this case, the filter uses a search picker restricted to the linked schema.</source>
<target xml:lang="en-XX">Ein Link-Attribut, z. B. eine Marke, die mit einem Produkt verknüpft ist. In diesem Fall verwendet der Filter eine Suchauswahl, die auf das verknüpfte Schema beschränkt ist.</target>
</trans-unit>
<trans-unit id="tu15" xml:space="preserve">
<source xml:lang="en-US">A sub-attribute of a link, for example the full name of a linked folder, or the email of a linked recipient.</source>
<target xml:lang="en-XX">Ein Unterattribut eines Links, z. B. der vollständige Name eines verknüpften Ordners oder die E-Mail-Adresse einer verknüpften Empfängerin bzw. eines verknüpften Empfängers.</target>
</trans-unit>

Um einen Filter zu entfernen, klicken Sie auf das Symbol mit den Auslassungspunkten in der Zeile und wählen Sie <ph id="5" ctype="x-STRONG_EMPHASIS">**[!UICONTROL </ph>Löschen<ph id="7" ctype="x-LINK_REF">]**</ph> aus.</target>
